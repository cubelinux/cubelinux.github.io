THE APPROACH

A desktop built as a system

Choose a letter or follow the slideshow to see how each part fits into the desktop.

Fedora provides cubelinux's Linux base and package ecosystem. bootc makes cubelinux a container-driven operating system by building the desktop, system tools, and defaults into one versioned OCI image. Updates stage a new OSTree deployment while your current system keeps running, then switch to it on restart. The previous deployment remains available for rollback.

KDE Plasma provides the desktop, with cubelinux's first-boot setup and familiar desktop tools.

KDE Discover installs Flathub apps as Flatpaks, with sandbox permissions controlling each app's access. cubelinux vshell uses unprivileged LXC for a persistent Fedora workspace with shared folders and Fedora app launchers. Flatpak apps, the Fedora environment, and the bootc system image follow separate update paths.
