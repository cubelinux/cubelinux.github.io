THE APPROACH

A desktop built as a system

cubelinux uses Fedora as its Linux base and package ecosystem. bootc builds the desktop, system tools, and defaults into one versioned OCI image. Updates stage a new OSTree deployment while your current system keeps running, then switch to it on restart. The previous deployment remains available for rollback.

KDE Plasma provides the desktop, with cubelinux's first-boot setup and familiar desktop tools.

VShell uses a separate Linux runtime with KDE Discover and Flatpak for installing apps. It can surface graphical apps in Plasma and share selected folders. The bootc host, VShell runtime, and Flatpak apps each follow their own update path.
