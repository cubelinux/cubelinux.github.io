BUILT IN PUBLIC

One distro, three repositories

cubelinux is taking shape across a system image and two companion desktop projects.

01 / SYSTEM

Fedora bootc image

The main repository builds a customized Fedora 44 bootc image with KDE Plasma and the cubelinux desktop setup.

Explore the system repo ↗ 02 / UPDATES

Bootc Updater

A KDE app in development for checking for updates, staging downloads, and applying an update after a confirmed restart.

Explore the updater repo ↗ 03 / VIRTUAL SHELL

VShell

A KDE setup app for a persistent Fedora LXC environment. Its container setup and host integration are still being developed.

THE APPROACH

A desktop built as a system

cubelinux starts with Fedora bootc, a KDE Plasma desktop, and a system image assembled from a versioned package manifest. The companion projects explore image updates and an isolated Fedora workspace.

  • AFedora bootcImage-based system foundation
  • BKDE PlasmaDesktop environment and setup flow
  • CLXC + VShellPersistent, unprivileged Fedora environment
